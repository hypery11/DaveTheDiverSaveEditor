Mac 版《潜水员戴夫》存档修改器

DiveSaveEd 是一款免费开源的 macOS 原生应用，在游戏关闭时离线修改你的 《潜水员戴夫》存档文件。不用 Wine、不用 Cheat Engine、不注入进程、不需要账号、全程不联网。

免费 · MIT 协议 macOS 14+ Apple Silicon + Intel 已签名并公证 四种语言

下载最新版本 在 GitHub 上查看源码

下载 .dmg，把应用拖进“应用程序”文件夹即可。应用已经过 Apple 签名与公证。

它能做什么

《潜水员戴夫》把游戏进度保存在你 Mac 上的一个存档文件里。DiveSaveEd 打开这个文件、解码、 让你改掉在意的数值、再写回去，然后关闭。整个工具就是这么回事。它从不附加到游戏进程，从不读写游戏内存， 也从不改动游戏本体程序——正因如此，它不需要游戏处于运行状态，而且在游戏运行时会拒绝写入。

这款游戏的存档修改器几乎清一色只有 Windows 版，在 Mac 上意味着得用 Wine、CrossOver 或虚拟机。 而这一款是真正的 Mac 应用。

仅支持 macOS 上的 Steam 版 不支持 Nintendo Switch 与 PlayStation 存档——那些是主机存档，本工具无法读取。 Xbox / Microsoft Store 版则根本没有 Mac 版。

功能

  • 货币

    金币、贝币、匠人之火、研究点数、COOKSTA 粉丝数、信任度与伪造点数。可以按 ±10 / 100 / 1000 微调、 直接输入具体数值，或一键拉满。“重置”会还原成你打开存档时的原始数值。

  • 批量填充

    每项一键完成——已有食材、全部食材（自动识别 DLC）、2 号店分店库存、员工等级、通用物品、制作材料、 鲛人村、农场种子、已捕鱼类等级——也可以用一键全部拉满同时执行全部。

  • 按名称搜索，不用找 ID

    应用内置物品数据库，你可以按物品的真实名称浏览并修改任意单个物品，不用再去表格里翻数字 ID。

  • 每一步都能回退

    所有批量操作都可以在应用内撤销，每次写入前都会先生成带时间戳的备份，并且有专门的恢复界面， 可以回滚到其中任意一份。

  • 只读的原始数据检视器

    把整个解码后的存档当作格式化 JSON 来搜索。刻意做成只读：手动改动原始数值可能让进度标记乱序， 导致这一周目卡死。

  • 多存档位

    自动识别游戏里的每一个存档，让你自己挑要改哪一个——而且不用告诉它存档在哪，它自己就能找到。

  • 四种语言

    English、简体中文、繁體中文、한국어。含非 ASCII 文本的存档都能正确读写，不会出现乱码。

  • 适配 DLC

    “In the Jungle”（丛林）DLC 的食材已经适配，而且应用只会注入你的存档中标记为“已安装”的那些 DLC 的内容。

这样改安全吗？

安全是一开始就定下的设计约束，不是事后补的：

  • 《潜水员戴夫》运行期间拒绝写入，存档文件被其他程序占用时同样拒绝。
  • 每次写入前自动生成带时间戳的备份，并提供恢复界面。
  • 批量撤销，覆盖每一个批量操作。
  • 写入任何内容之前都会先给出更改预览。
  • 批量填充时跳过易腐的突变鱼（《渔帆暗涌》联动的捕获物）——游戏在加载时会丢弃囤积的突变鱼，硬填反而会把你真正钓到的鱼清掉。
  • 基于 MIT 协议开源。运行之前，每一行代码你都可以先读一遍。

另外，不会被封号：《潜水员戴夫》是纯单机游戏，没有联机、没有排行榜，也没有任何反作弊程序。 做这个工具，是为了让你能够备份、修复并“解放”自己的单机存档，不用再重复刷。

⚠️ Steam Cloud 会悄悄还原你的修改 这是“改了没生效”最常见的原因。先彻底退出游戏，把《潜水员戴夫》的 Steam Cloud 关掉，再动手修改—— 完整的四步顺序看这里。
